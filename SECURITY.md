# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in LangRails, please report it privately by emailing **security@promptrails.ai**.

Please do **not** report security vulnerabilities through public GitHub issues or discussions.

## What to Include

- A description of the vulnerability
- Steps to reproduce (if applicable)
- The version(s) affected
- Any potential impact

## Response Timeline

- **Acknowledgment:** within 48 hours
- **Initial assessment:** within 5 business days
- **Fix timeline:** depends on severity, communicated during assessment

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | ✅        |
| older   | ❌        |

We recommend always using the latest release.
